
# JavaScript Basics

## Objective
To create basic JavaScript programs, organize them in a
GitHub repository, and deploy them as a static website
using GitHub Pages.

## Technologies Used
- HTML
- JavaScript
- GitHub
- GitHub Pages

## Project Description
This project contains basic JavaScript programs.
The homepage displays student details and provides links
to individual programs.
